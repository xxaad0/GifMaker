
# Gif maker with Tkinter and Pillow

# I used tkinter for dialogs and pillow in order to process images

## features
- images can be selected and frames can be set
- also we can resize images and the gif keeps looping.
-  palettes are handled and there is little GUI.

## Requirements
- Python 3.9+
- Pillow

Install dependenecies are as follows:
pip install pillow

## Use
- Run it via python main.py
- Click the button to choose images and then enter according to the screen prompts.
- Then It will confirm and you can check the image.

## Notes 
- 256 colors are supported.
- 0 can be set for the size if no resizing is needed.
